🌅 iOS 배경화면 자동화 설정 가이드

추천 골든타임 3회(일출 시각, 08:40, 14:00)에 맞춰 잠금화면 시간표가 자동으로 갱신되도록 자동화 일정을 등록하는 상세 단계입니다.

1단계: 📲 단축어 다운로드 및 URL 교체 (⚠️ 필수)

배경화면 탭 하단의 [iPhone 단축어 등록] 버튼을 터치하면 이미지 URL이 자동으로 클립보드에 복사되며 단축어 다운로드 창이 열립니다.

⚠️ 단축어를 추가한 후 반드시 해주세요:

단축어 앱에서 다운로드된 단축어의 [설정(편집)] 화면으로 들어간 뒤, 맨 위의 ${YourLink}라고 써진 칸을 지우고, 복사되어 있는 실제 주소를 [붙여넣기] 해줍니다.

2단계: ⚙️ 개인용 자동화 3종 추가 (단축어 앱 실행)

아이폰 [단축어 앱] ➔ 하단 [자동화] 탭 ➔ 우측 상단 [+] 버튼을 차례로 누르고 아래의 3가지 시간대를 각각 등록해 줍니다.

  • 🌅 일출 시간 (아침 등교 전 최초 갱신)
    [하루 중 특정 시간] 선택 ➔ [일출] 체크 ➔ 실행 옵션을 [확인 없이 실행]으로 스위칭 ➔ [용정시간표 배경화면] 단축어 실행으로 동작 등록
  • ⏰ 오전 08:40 (조회 및 1교시 시작 전 갱신)
    [하루 중 특정 시간] 선택 ➔ 시간을 [08:40]으로 기입 ➔ 실행 옵션을 [확인 없이 실행]으로 선택 ➔ 동일 단축어 실행 등록
  • 🕒 오후 14:00 (오후 수업 교체 실시간 갱신)
    [하루 중 특정 시간] 선택 ➔ 시간을 [14:00]으로 기입 ➔ 실행 옵션을 [확인 없이 실행]으로 선택 ➔ 동일 단축어 실행 등록

💡 실행 시 배너 알림 안 뜨게 하는 꿀팁

각각 등록한 자동화 설정 화면 내부로 진입하여 [실행 시 알림] 스위치를 비활성화(끔)로 두시면, 매 실행 시 화면 상단 배너 알림 없이 아주 부드럽고 조용하게 배경화면이 자동으로 교체됩니다!

01개인정보 처리 목적

서비스는 전자시간표 조회, API key 발급, 슬라이드쇼 표시, 관리자 입력 데이터 저장 및 동기화, 오류 확인, 이용 통계 분석을 위해 필요한 정보를 처리합니다.

시간표, 행사, 안내사항에는 학생 이름, 연락처, 주민등록번호 등 개인을 직접 식별할 수 있는 정보를 입력하지 않는 것을 원칙으로 합니다. 다만 시간표 조회 화면에는 반별 과목 담당 교사의 이름이 함께 표시될 수 있습니다.

02처리하는 개인정보 항목

  • 관리자 입력 정보: 시간표, 반별 과목 담당 교사 이름, 단일교과 변경, 행사, 안내사항, 슬라이드쇼 설정
  • API 신청 정보: 사용처 이름, 이메일 주소, 전화번호, 이메일 인증 및 발급 기록
  • 자동 생성 정보: 접속 기록, 페이지 이용 기록, 브라우저 및 기기 정보, 대략적인 지역 정보, 쿠키 또는 유사 식별자
  • 브라우저 저장 정보: 선택 학급, 화면 테마, 마지막 저장 시각, 관리자 로그인 세션 정보

03처리 및 보유 기간

시간표, 행사, 안내사항 등 운영 데이터는 서비스 제공에 필요한 기간 동안 보관하며, 더 이상 필요하지 않으면 관리자 기능 또는 내부 정리 기준에 따라 삭제합니다.

API 신청 연락처와 발급 기록은 API key 운영, 오용 대응 및 문의 처리를 위해 key 폐기 후에도 필요한 기간 동안 보관하며, 삭제 요청이 확인되면 관련 법령상 보관 의무가 없는 범위에서 삭제합니다.

브라우저에 저장되는 설정 값은 사용자가 브라우저 데이터 삭제 기능으로 직접 삭제할 수 있습니다. Google Analytics 4의 이용 통계 정보는 Google의 보관 설정 및 정책에 따라 보관됩니다.

04제3자 제공

서비스는 법령에 따른 경우를 제외하고 이용자의 개인정보를 외부에 판매하거나 임의로 제공하지 않습니다.

다만 서비스 운영 과정에서 아래 외부 서비스가 사용되며, 각 서비스 제공자의 정책에 따라 접속 정보와 이용 통계 정보가 처리될 수 있습니다.

05처리 위탁 및 국외 이전

  • Supabase Inc.: 시간표 데이터 저장, 동기화, 관리자 저장 기능 제공
  • Resend Inc.: API 신청 이메일 인증번호 발송
  • Google LLC: Google Analytics 4를 통한 이용 통계 분석
  • Netlify Inc.: 정적 웹사이트 호스팅 및 배포

위 서비스는 미국 등 국외에 위치한 인프라를 사용할 수 있으며, 서비스 제공에 필요한 범위에서 접속 정보, 이용 통계 정보, 관리자 입력 데이터, API 신청 이메일이 전송 또는 보관될 수 있습니다.

06정보주체의 권리 행사

이용자는 본인에 관한 개인정보의 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 서비스 특성상 회원 계정을 운영하지 않으므로, 요청 시 확인 가능한 범위 안에서 처리합니다.

요청은 아래 문의처로 접수할 수 있으며, 법령상 보관이 필요한 정보는 해당 기간 동안 분리 보관하거나 제한적으로 처리될 수 있습니다.

07파기 절차 및 방법

보유 기간이 끝났거나 처리 목적이 달성된 정보는 복구하기 어려운 방법으로 삭제합니다. 전자 파일 형태의 정보는 저장 매체에서 삭제하고, 브라우저 저장 정보는 사용자의 브라우저 데이터 삭제 기능을 통해 삭제할 수 있습니다.
